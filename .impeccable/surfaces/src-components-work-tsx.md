## Direction contract

THESIS: The work is a ruled index, not a shelf. Each project is one line in an open ledger — number, Machine-caps title, category, and stack on a single grid row that breathes. No cards, no panels, no themed substrate; the section inherits the site's dark neutral tokens (bg / ink / ink-2 / accent rust / rule) and a single hairline rule separates the rows. Opening an entry flips a quiet sheet over the viewport for the full write-up. Refuses the AI-card grid, the decorated substrate past, and any decorative implant. OWN-WORLD: neutral dark background, hairline `--color-rule` separators, Machine condensed caps for titles and section heading, Space Mono for numbers/stacks/meta labels, Breton italic for the category and the single teaser line per project, rust accent reserved for the in-development chip, hover, and the active underline. STORY: the visitor understands each project was engineered with intent — the ledger reads as a record of real building — then opens an entry and continues to contact. FIRST VIEWPORT: heading "Selected work." in large Machine caps with a one-line sub, then three ruled rows; the primary action is opening a row. FORM: user-pinned minimal direction (supersedes the Circuit Board world, seed 5c069a82). TYPOGRAPHY CONTRACT: font families are declared verbatim (`'Machine'`, `'Space Mono'`, `'Breton'`) — never `var(--font-*)`, which is shadowed to generic system fonts by injected theme tokens. FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
